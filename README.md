## 👨‍💻 About Me 🇧🇷

Sou estudante de Informática para Internet no IFRN, focado em me tornar desenvolvedor Front-end.  
Acredito que tecnologia não é apenas código — é construção de experiência, percepção e impacto.

Tenho afinidade com Python, HTML, CSS e Banco de Dados, além de conhecimentos em JavaScript, Node e redes (Cisco).  
Gosto de entender o sistema como um todo: da interface ao servidor, da lógica à infraestrutura.

Sou movido por criatividade e ambição.  
Observo antes de agir, analiso antes de decidir — mas quando executo, faço com visão.

Atleta amador de Basquete e Natação, aprendi que constância supera talento momentâneo.  
Levo para o código a mesma disciplina que levo para o treino.

Valorizo o processo, a evolução constante e o reconhecimento que vem como consequência do esforço bem direcionado.
